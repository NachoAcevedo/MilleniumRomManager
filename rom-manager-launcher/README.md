# Steam ROM Manager Launcher

Windows plugin for Millennium. It opens the installed Steam ROM Manager from **Add a Non-Steam Game**, shows a loading indicator, and brings the window forward. The SRM window is opened independently through Windows Explorer. If Steam closes and successfully reopens while SRM is still open, the launcher asks SRM to close normally.

## Install

1. Install Millennium and the official [Steam ROM Manager](https://github.com/SteamGridDB/steam-rom-manager/releases) using its default per-user Windows install location.
2. Download the Launcher ZIP from Releases and extract the `rom-manager-launcher` folder into `Steam\millennium\plugins`.
3. Restart Steam, enable **Steam ROM Manager en Steam** in Millennium, and disable the Importer if active.
